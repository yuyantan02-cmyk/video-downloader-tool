后端没启动？两条路，选一条

这个网页是前台，真正干活的是一个很小的 Python 后端（yt-dlp + FastAPI，就是先前已经做好的那套）。静态网页 —— 包括 GitHub Pages 那种 xxx.github.io 地址 —— 只能放页面、跑不了 Python，所以下载必须连上一个后端。连上之后，这个页面就是完整的下载器。

A在自己电脑上启动（免费，3 分钟）

用之前发你的 video-downloader-tool 文件夹（或压缩包解压出来的那个）。在文件夹里打开「终端」，依次运行：

cd ~/Downloads/video-downloader-tool python3 -m venv .venv source .venv/bin/activate pip install -r requirements.txt uvicorn app.main:app --host 127.0.0.1 --port 8000

看到 Uvicorn running on http://127.0.0.1:8000 就说明起来了，终端窗口别关，回到这个页面点「检测连接」。
提示找不到 ffmpeg 时先运行 brew install ffmpeg。Windows 把第二、三行换成 py -m venv .venv 和 .venv\Scripts\activate，其余一样。

B部署到云上，手机也能用（已部署）

把代码仓库推到 GitHub 后（仓库里已经带了 Dockerfile、docker-compose.yml 和 render.yaml），在 Render 这类平台上选「New → Web Service / Blueprint」，指向这个仓库部署即可。部署完会得到一个公开地址，长这样：

# 举例，换成你自己部署得到的地址 https://video-downloader-tool-5ffe.onrender.com

把这个地址填到上面「解析后端地址」里，点「检测连接」变绿就能用了 —— 之后手机、平板打开这个网页填同一个地址，一样能下。

连不上时，也可以直接用命令行

后端代码里带了一个命令行入口，效果和网页下载完全一样。你粘贴链接后，下面这行命令会自动生成，复制到终端里运行即可（需要先完成左边 A 的前三行安装步骤）：

python cli.py "（先在上面粘贴一个链接）" --confirm --quality best

它是怎样保存视频的

仅获取公开可访问的视频流，不擦除水印，不修改画面或作者标识。平台是否提供无水印源因视频而异；未经逐文件检查，一律显示「未验证」。云端使用时，文件先暂存在服务器，默认一小时后清理。

常见问题

为什么打开 127.0.0.1:8000 显示「无法连接服务器」？

因为 127.0.0.1 指的是「你自己的这台电脑」，不是云端的某个网站。那个小服务没在你电脑上跑着的时候，这个地址后面什么都没有，浏览器自然连不上。按上面 A 的步骤先把服务跑起来，再刷新就行 —— 这个网页版就是为了解决这件事才做的：页面随时能打开，后端连上就开工。

下完发现画质只有 720p，是被压缩了吗？

工具不会放大视频。当前网络和访问权限下可获取的最高档，可能低于平台登录后的画质。格式列表最多展示 12 项，最终文件分辨率以下载后的实际检测值为准。

提示「需要登录 / 私密内容」怎么办？

说明这个视频是私密的、要登录才能看，或者有年龄 / DRM 限制。工具不登录账号、不导入或持久保存账号 Cookie，这类内容会直接拒绝。你自己的作品遇到这种情况，用平台官方的导出功能拿原文件最稳妥。

下回来的视频怎么还有水印？

两种可能：一是创作者上传时就把水印烧进了画面本身，那它就是原片的一部分，谁都拿不到「没烧过」的版本；二是平台这次没提供干净流。工具不会用涂抹或 AI 去硬擦，会原样返回并在结果里说明。

昨天还能解析，今天突然失败了？

大概率是平台又改接口了，这是这类工具最常见的故障。请先记录错误类型，可能是网络、验证、内容不可访问或解析器变化。维护者需要同步验证 yt-dlp、EJS 与运行环境；公网网站用户无需安装 Python。

使用边界，先说清

只下载你本人上传的、已获得权利人授权的，或平台明确允许公开下载的内容。下载文件旁的 .json 会保留作者、标题和原链接，请勿抹去署名、勿二次分发。私密、需登录、DRM 保护的内容，工具一律拒绝。
