社交视频下载器

粘贴一个视频分享链接，下载平台提供的最高画质源流。只取干净源流，不涂抹、不做 AI 去水印。

合规提醒：仅用于你本人上传的内容、已获得权利人授权的内容，或可公开下载的内容。下载后请保留作者信息，不要二次分发。私密 / 需登录 / DRM 保护的视频不会下载。
关于这个 GitHub Pages 网址：GitHub Pages 只能托管静态网页，不能运行 Python 后端（yt-dlp / FastAPI）。所以这个页面本身不直接下载，它需要连一个后端才能真正解析。 两种用法：① 在你电脑上跑起后端后，把下面“后端地址”填成 http://127.0.0.1:8000；② 部署一个后端（见仓库 README 的 Render 一键部署），把它的公开地址填进来。 如果后端没启动，就会像之前那样显示“无法连接服务器”。

等待操作…先确认后端已启动，否则会提示无法连接。

支持：YouTube、TikTok、X、Instagram、Facebook、Threads；抖音、小红书、快手、B站走 yt-dlp；微信视频号需用官方导出。源码见 GitHub 仓库 README。
