# Roadmap

本分支提供七目标平台的解析适配与共享安全下载流程，状态以 [acceptance.md](acceptance.md) 为准。

1. 当前：完成自动化与合成媒体检查；真实平台验收由用户自行执行。微信视频号通用下载 BLOCKED。
2. 下一步：用有权下载的标准链接、短链和分享文案逐平台记录真实结果；在独立 Render 测试服务复验，不能拿本地结果替代云端结果。
3. 根据真实失败证据局部修复适配器，不以换客户端规避访问限制，不引入未授权第三方解析。
4. 通过回归和授权检查后再考虑生产发布；未经批准不合并或部署。

暂不包含：批量抓取、会员收费、账号登录、AI 去水印、视频 MD5 修改、未经授权的视频号解密。
